# RunaShared Releases

Binarios públicos de RunaShared para descarga.

## Descargas

### Windows
- [v1.0.0](v1.0.0/windows/) - Ejecutable `.exe`

### Linux
- [v1.0.0](v1.0.0/linux/) - Binario ejecutable

## Instalación

### Windows
1. Descarga el `.exe` desde la carpeta de la versión
2. Ejecuta `RunaShared.exe`
3. Usuario por defecto: `admin` / Contraseña: `admin`

### Linux
1. Descarga el binario desde la carpeta de la versión
2. Da permisos de ejecución: `chmod +x RunaShared`
3. Ejecuta: `./RunaShared`
4. Usuario por defecto: `admin` / Contraseña: `admin`
